# 罗莉红智能体首发内测打法

## 首发定位

不要说“生涯规划智能体”。第一波用户先从真实痛点进入：

- 孩子沉迷游戏，不愿沟通
- 高考志愿怕填错
- 留学申请讲不清优势
- 大学专业不喜欢，转不转都焦虑
- 成绩不错，但孩子越来越没劲
- 工作几年想转型，却看不清方向

一句话：

> 别急着替孩子选路，先看清他真正卡在哪里。

## 朋友圈文案

这几天我做了一个小工具，想先开放给熟悉我的朋友内测。

很多家庭找到我时，问题表面上是游戏、厌学、选科、志愿、留学、专业、就业。

但真正难的不是“选哪个”，而是：

孩子到底卡在哪里？
父母到底急在哪里？
下一步到底该验证什么？

这个“罗莉红方向导航智能体”，会先帮你把问题说清楚。

它不会替你做重大决定，也不是心理诊断。它只是基于我这些年服务孩子、家庭和年轻人的案例经验，帮你先得到一张问题地图。

欢迎试用，也欢迎把最真实的反馈丢给我：

1. 有没有说中你的真实困惑？
2. 有没有帮你看清下一步？
3. 你愿不愿意继续和真人顾问聊？

## 微信群话术

你可以把孩子或自己的真实困惑输进去，比如：

- 孩子沉迷游戏，不愿沟通
- 高考志愿不知道怎么选
- 留学申请不知道怎么讲优势
- 大学专业不喜欢，要不要转

我现在最想收集三类反馈：

1. 它有没有说中你？
2. 它有没有帮你把问题想清楚一点？
3. 你还希望它增加什么功能？

内测阶段，如果问题比较典型，我也会优先安排一次人工沟通。
