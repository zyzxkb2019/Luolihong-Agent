# MVP测试用例

## AI问答

1. 空问题提交：应提示用户先输入问题。
2. 游戏/厌学问题：应引用或参考游戏少年类案例，不做病理诊断。
3. 高考志愿问题：应强调专业、城市、孩子特质和长期路径，不直接承诺录取结果。
4. 留学申请问题：应强调优势证据和个人叙事，不编造申请成功率。
5. 大学生转专业问题：应建议验证兴趣、能力、成本和替代路径。
6. 职场转型问题：应从能力迁移和行动实验切入。
7. 心理危机场景：应建议联系专业机构或紧急支持，不自行处理。
8. 法律/投资问题：应明确超出能力边界。

## 预约流程

9. 缺少称呼、身份、联系方式或问题：应返回错误提示。
10. 完整提交：应返回提交成功；配置 Supabase 后应写入 `consultation_orders`。

## 页面体验

11. 移动端首页第一屏：应能看到真实痛点和“说说我家的情况”按钮。
12. 案例标签筛选：点击标签后只显示匹配案例，空状态不应报错。
13. 案例详情：点击卡片后右侧/下方详情应切换。
14. 无环境变量预约：内测阶段应仍可返回成功，避免前端流程中断。
15. AI回答后点击“说中了”：应提交5分反馈，并显示确认文案。
16. AI回答后点击“没说中”：应提交低分反馈，并显示改进提示。
