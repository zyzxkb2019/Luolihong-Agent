# 罗莉红智能体 MVP

这是“罗莉红个人智能体”的第一版网站 MVP，目标是在私域、朋友圈、公众号和视频号中快速验证：

- 家长是否愿意把真实困惑输入给智能体
- 案例故事是否能触发共鸣和信任
- 预约表单是否能沉淀高意向线索

## 核心功能

- 首页痛点入口
- 罗莉红个人 IP 与专业背书
- 方法论介绍
- 脱敏案例故事库
- AI 初步问答助手
- 轻量预约表单

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 可选环境变量

预约表单默认会返回成功信息。若配置 Supabase，则会写入 `consultation_orders` 表。

```bash
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
```

## 首发运营建议

第一版不要宣传“生涯规划”概念，先用家长真实痛点切入：

- 孩子沉迷游戏，不愿沟通
- 高考志愿怕一步填错
- 留学申请讲不清优势
- 大学专业不喜欢，转不转都焦虑
- 工作几年想转型，却看不清方向

目标不是一次做完，而是在 48 小时内跑通“访问 - 提问 - 看案例 - 留资”的闭环。
